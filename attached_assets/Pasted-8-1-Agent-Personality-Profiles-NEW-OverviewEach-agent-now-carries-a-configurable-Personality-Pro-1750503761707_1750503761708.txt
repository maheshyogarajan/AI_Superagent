8.1  Agent Personality Profiles (NEW)

OverviewEach agent now carries a configurable Personality Profile inspired by real‑world figures. The profile steers tone, risk tolerance, reasoning depth, default model temperature, and preferred communication style, while staying fully compatible with the existing MCP envelope.

Example Profile Schema

{
  "profile_id": "SteveJobs",
  "name": "Steve Jobs",
  "tone": "visionary, perfection‑seeking",
  "decision_style": "bold, design‑first, risk‑tolerant",
  "communication_style": "story‑driven, direct",
  "max_temperature": 0.9
}

Implementation Hooks

New Module: create ai_super_agent/personalities/ containing one JSON file per profile.

BaseAgent Update: add optional personality_id: str = "Default"; on __init__ load profile into self.personality.

MCP Extension: optionally embed context.personality so downstream agents & UI display active persona.

Temperature Clamp: LLM calls use min(requested_temp, self.personality["max_temperature"]).
